# DailyJournal Pro

Secure personal journaling platform built with Laravel 12, PHP 8.3, MySQL, Bootstrap 5, Laravel Breeze-style authentication, Chart.js, DataTables, SweetAlert2, and Font Awesome.

Demo user:

- Email: `demo@dailyjournal.test`
- Password: `password`

## Features

- Registration, login, password reset, email verification, profile, avatar, bio, change password, logout
- Journal CRUD with rich text content, moods, tags, favorites, privacy, archive status, and cover images
- Dashboard analytics for totals, monthly entries, favorites, moods, writing activity, growth, and streak
- Calendar view with entry indicators
- Tag management and filters
- PDF export per entry and ZIP archive download for all entries
- Form validation, CSRF protection, policies, secure storage, password hashing

See the `docs` folder for installation, schema, and structure notes.
